# 白酒Ⅲ最高质量公司评分公式

目标：只在白酒Ⅲ公司池里选出“企业质量最高”的一家公司，不讨论买不买、什么时候买、估值贵不贵。

基础公司池见：[公司清单.md](./公司清单.md)。

## 总公式

```text
QualityScore =
100 × RiskFactor × PurityFactor × (
  0.25 × R(ROIC_5Y_Median)
+ 0.20 × R(ROE_5Y_Median)
+ 0.20 × R(GrossMargin_5Y_Median)
+ 0.15 × R(NP_CAGR_5Y)
+ 0.15 × R(OCF_NP_5Y)
+ 0.05 × (1 - R(ROE_5Y_Std))
)
```

最终选择：

```text
BestCompany = argmax(QualityScore)
```

也就是：把所有白酒Ⅲ公司都算一遍，分数最高的那家公司就是“最高质量公司”。

## 指标定义

| 指标 | 含义 | 方向 |
|---|---|---|
| ROIC_5Y_Median | 最近 5 年 ROIC 中位数 | 越高越好 |
| ROE_5Y_Median | 最近 5 年 ROE 中位数 | 越高越好 |
| GrossMargin_5Y_Median | 最近 5 年毛利率中位数 | 越高越好 |
| NP_CAGR_5Y | 最近 5 年归母净利润复合增速 | 越高越好 |
| OCF_NP_5Y | 最近 5 年经营现金流净额合计 / 归母净利润合计 | 越高越好 |
| ROE_5Y_Std | 最近 5 年 ROE 标准差 | 越低越好 |

其中 `R(x)` 表示该指标在白酒Ⅲ有效股票池中的百分位排名，取值为 0 到 1。

```text
R(x) = 该公司该指标的行业内百分位排名
```

例如某公司 `ROIC_5Y_Median` 在白酒Ⅲ里排名越靠前，`R(ROIC_5Y_Median)` 就越接近 1。

## 系数规则

### RiskFactor

```text
正常公司 = 1
ST、*ST、退市风险警示 = 0
最近一年归母净利润为负 = 0
重大财务造假、重大监管处罚 = 0
```

只要 `RiskFactor = 0`，公司直接不参与最高质量公司竞争。

### PurityFactor

```text
白酒收入占比 >= 80%：1.0
白酒收入占比 50%-80%：0.7
白酒收入占比 < 50%：0.4
```

这个系数用于处理顺鑫农业这类非纯白酒公司。它可以参与计算，但不能和纯白酒公司完全等权比较。

## 公式含义

这个公式本质上只问 6 个问题：

1. 资本回报率是不是长期优秀；
2. 股东回报率是不是长期优秀；
3. 毛利率是不是体现品牌和定价权；
4. 利润是不是还能增长；
5. 利润是不是能变成真实现金流；
6. 盈利能力是不是稳定。

如果一家公司长期 ROIC 高、ROE 高、毛利率高、利润还能增长、现金流真实、ROE 波动又小，它就是白酒Ⅲ里质量最高的公司。

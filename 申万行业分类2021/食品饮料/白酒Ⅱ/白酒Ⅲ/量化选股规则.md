# 白酒Ⅲ量化选股规则

## 量化选股思路

白酒行业适合采用“质量优先、估值约束、动量确认”的多因子框架。行业内公司数量较少，不适合做过度复杂的机器学习模型，更适合用透明、可解释、可回测的打分体系。

核心目标不是找到单一年份利润最高的公司，而是筛选出长期盈利质量稳定、现金流真实、估值没有明显透支、股价趋势没有恶化的标的。

## 股票池处理

基础股票池为申万三级行业“白酒Ⅲ”全部成分股，成分股清单见：[公司清单.md](./公司清单.md)。

剔除规则：

| 规则 | 处理方式 |
|---|---|
| ST、*ST、退市风险警示 | 剔除 |
| 上市未满 3 年 | 剔除或降低权重 |
| 最近一期归母净利润为负 | 剔除 |
| 最近一期经营现金流净额为负且连续恶化 | 剔除 |
| 资产负债率异常高于行业多数公司 | 降低质量分 |
| 白酒业务占比明显偏低 | 单独标记，不与纯白酒公司直接比较 |

特殊说明：顺鑫农业含白酒业务但不是纯白酒公司，适合单独建模；*ST岩石应优先按风险警示规则剔除。

## 因子设计

建议采用 5 类因子，满分 100 分。

| 因子类别 | 权重 | 指标 |
|---|---:|---|
| 盈利质量 | 30% | ROE、ROIC、毛利率、净利率 |
| 成长能力 | 20% | 营收 CAGR、归母净利润 CAGR、扣非净利润 CAGR |
| 现金流质量 | 20% | 经营现金流 / 净利润、自由现金流、合同负债变化 |
| 估值与分红 | 20% | PE、PEG、股息率、分红率 |
| 市场趋势 | 10% | 6 个月动量、12 个月动量、相对行业强弱 |

## 具体指标口径

| 指标 | 计算方式 | 方向 |
|---|---|---|
| ROE_TTM | TTM 归母净利润 / 平均归母净资产 | 越高越好 |
| ROE_5Y_Median | 最近 5 年 ROE 中位数 | 越高越好 |
| ROE_5Y_Std | 最近 5 年 ROE 标准差 | 越低越好 |
| GrossMargin_TTM | TTM 毛利 / TTM 营收 | 越高越好 |
| NetMargin_TTM | TTM 归母净利润 / TTM 营收 | 越高越好 |
| Revenue_CAGR_5Y | 最近 5 年营收复合增速 | 越高越好 |
| NP_CAGR_5Y | 最近 5 年归母净利润复合增速 | 越高越好 |
| OCF_NP_5Y | 最近 5 年经营现金流净额合计 / 归母净利润合计 | 越高越好 |
| FCF_Yield | 自由现金流 / 总市值 | 越高越好 |
| ContractLiability_YoY | 合同负债同比增速 | 越高越好 |
| PE_TTM | 总市值 / TTM 归母净利润 | 越低越好 |
| PEG | PE_TTM / 未来或历史利润增速 | 越低越好 |
| DividendYield | 近 12 个月现金分红 / 总市值 | 越高越好 |
| PayoutRatio | 现金分红 / 归母净利润 | 适中偏高更好，可设 40%-90% 为较优区间 |
| Momentum_6M | 最近 6 个月涨跌幅，剔除最近 20 个交易日 | 越高越好 |
| RS_12M | 个股 12 个月涨跌幅 - 白酒行业指数涨跌幅 | 越高越好 |

## 标准化方法

白酒股票池较小，建议使用行业内分位数打分，而不是直接使用原始数值。

单项因子分数：

```text
正向指标分数 = percentile_rank(x)
反向指标分数 = 1 - percentile_rank(x)
```

其中 `percentile_rank(x)` 表示该股票在白酒行业股票池中的分位数，取值范围为 0 到 1。

为避免极端值影响，所有连续变量建议先做缩尾处理：

```text
低于 P5 的值替换为 P5
高于 P95 的值替换为 P95
```

## 综合评分公式

```text
QualityScore =
  0.30 * ProfitabilityScore
+ 0.20 * GrowthScore
+ 0.20 * CashflowScore
+ 0.20 * ValuationScore
+ 0.10 * MomentumScore
```

子项可按以下方式计算：

```text
ProfitabilityScore =
  0.30 * ROE_TTM_score
+ 0.30 * ROE_5Y_Median_score
+ 0.20 * GrossMargin_TTM_score
+ 0.20 * NetMargin_TTM_score
+ 0.10 * ROE_5Y_Std_inverse_score
```

```text
GrowthScore =
  0.40 * Revenue_CAGR_5Y_score
+ 0.40 * NP_CAGR_5Y_score
+ 0.20 * Recent_NP_YoY_score
```

```text
CashflowScore =
  0.50 * OCF_NP_5Y_score
+ 0.30 * FCF_Yield_score
+ 0.20 * ContractLiability_YoY_score
```

```text
ValuationScore =
  0.40 * PE_TTM_score
+ 0.25 * PEG_score
+ 0.25 * DividendYield_score
+ 0.10 * PayoutRatio_score
```

```text
MomentumScore =
  0.50 * Momentum_6M_score
+ 0.50 * RS_12M_score
```

注意：`ROE_5Y_Std_inverse_score` 是对 `ROE_5Y_Std` 做反向分位数处理后的得分，即 ROE 波动越低，得分越高。

## 组合构建规则

行业内样本只有约 20 家，不建议过度分散。

| 组合类型 | 规则 |
|---|---|
| 稳健型 | 选择综合评分前 3 名 |
| 平衡型 | 选择综合评分前 5 名 |
| 进取型 | 选择综合评分前 5 名，同时提高成长与动量权重 |

权重规则：

```text
个股权重 = 综合评分 / 入选股票综合评分合计
```

约束条件：

| 约束 | 建议 |
|---|---|
| 单只股票最高权重 | 40% |
| 单只股票最低权重 | 10% |
| 高端白酒合计权重 | 不低于 40% |
| ST 或风险警示股票 | 0% |
| 非纯白酒公司 | 单只权重不高于 10% |

## 调仓规则

| 项目 | 建议 |
|---|---|
| 调仓频率 | 季度调仓，年报和半年报后重点更新 |
| 财务数据更新 | 使用已披露定期报告，避免未来函数 |
| 价格数据 | 使用调仓日前一个交易日收盘价 |
| 缓冲区 | 当前持仓跌出前 7 名才卖出，避免频繁换仓 |
| 止损 | 行业策略不建议机械止损，优先用基本面剔除 |

## 风险控制

出现以下情况时，个股应降权或剔除：

| 风险信号 | 处理 |
|---|---|
| 连续两个报告期收入或利润负增长 | 降权 |
| 经营现金流 / 净利润连续低于 0.8 | 降权 |
| 合同负债连续下降且存货上升 | 降权 |
| PE 显著高于自身 5 年中位数且利润增速下行 | 降权 |
| 批价长期倒挂或渠道库存显著高企 | 降权 |
| 财务造假、监管处罚、重大内控问题 | 剔除 |

## 推荐回测口径

回测时至少覆盖一轮白酒景气上行和下行周期，建议从 2016 年开始。

核心观察指标：

| 指标 | 含义 |
|---|---|
| 年化收益率 | 策略长期回报 |
| 最大回撤 | 下行风险 |
| 夏普比率 | 风险调整后收益 |
| 相对申万白酒指数超额收益 | 是否跑赢行业 |
| 换手率 | 策略交易成本 |
| 胜率 | 每次调仓后赚钱概率 |

比较基准：

- 申万白酒Ⅲ指数；
- 等权白酒组合；
- 贵州茅台单一持有；
- 高端白酒三家公司等权组合。

| 5 年经营现金流 / 净利润 | 20% |

| PE_TTM | 15% |
| 股息率 | 10% |

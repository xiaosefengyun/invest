# 白酒Ⅲ最高质量公司量化选股规则

目标：只在白酒Ⅲ公司池里选出“企业质量最高”的一家公司，不讨论买不买、什么时候买、估值贵不贵。

基础公司池见：[公司清单.md](./公司清单.md)。

## 公式

### 1. 候选池

```text
RawPool = 白酒Ⅲ全部公司
ValidPool = RawPool 中 RiskFactor > 0 且 ChannelHealthFactor > 0 的公司
CandidatePool = ValidPool 中 EligibleForBestCompany = True 的公司

BestCompany = CandidatePool 中 QualityScore 最高的公司
```

### 2. 风险系数

```text
RiskFactor 初始值 = 1.0

若触发以下任一条件：
RiskFactor = 0
EligibleForBestCompany = False

触发条件：
ST、*ST、退市风险警示
最近一年归母净利润为负
最近 5 年内有 2 年及以上归母净利润为负
触发 SevereCashFlowAbnormal = True
触发 RegulatoryMajorRisk = True
审计意见为非标准无保留意见

若最近一年扣非归母净利润为负：
RiskFactor = min(RiskFactor, 0.5)

若最近 5 年内有 1 年归母净利润为负：
RiskFactor = min(RiskFactor, 0.6)
```

### 3. 入选资格

```text
EligibleForBestCompany 初始值 = True

若触发以下任一条件：
EligibleForBestCompany = False

触发条件：
BaijiuRevenueRatio < 50%
ROIC_5Y_Median < 10%
OCF_NP_5Y < 0.8
GrossMargin_5Y_Median < 50%
最近 5 年营业收入 CAGR < 0 且归母净利润 CAGR < 0
最近 5 年扣非归母净利润 CAGR < 0 且最近一年扣非归母净利润同比下降
```

### 4. 主业纯度系数

```text
BaijiuRevenueRatio >= 80%：PurityFactor = 1.0
BaijiuRevenueRatio 50%-80%：PurityFactor = 0.7
BaijiuRevenueRatio < 50%：PurityFactor = 0.4
```

### 5. 渠道健康系数

```text
ChannelHealthFactor 初始值 = 1.0

ContractLiabilityRevenueRatio 连续两年下降，且 RevenueYoYGrowth 连续两年下降：-0.10
ReceivableRevenueRatio 高于行业 75 分位：-0.10
最近一年 OCF/NP < 0.8：-0.10
InventoryTurnoverDays 连续两年上升：-0.10
OCF_YoYGrowth 连续两年低于 NP_YoYGrowth：-0.10

若只触发普通扣分项：
ChannelHealthFactor = max(1.0 - 扣分合计, 0.6)

若触发 SevereChannelAbnormal = True：
ChannelHealthFactor = 0
EligibleForBestCompany = False
```

### 6. 百分位分数

所有指标都在 `ValidPool` 内横向比较。

```text
R(x) = (RankAscending(x) - 1) / (N - 1)

N = ValidPool 中该指标有有效数据的公司数量
RankAscending(x) = 从低到高排序后的名次

行业最高值 = 1
行业最低值 = 0
```

对于越低越好的指标：

```text
LowScore(x) = 1 - R(x)
```

并列值使用平均名次。若某个指标只有 1 家公司有有效数据，则该指标不参与打分，并把该指标权重在同一模块内按比例分配给其他可用指标。

### 7. 模块分

```text
OperatingQualityScore =
  0.40 × R(ROIC_5Y_Median)
+ 0.25 × R(OCF_NP_5Y)
+ 0.15 × R(FCF_NP_5Y)
+ 0.10 × R(ROE_5Y_Median)
+ 0.10 × R(NetMargin_5Y_Median)

BrandQualityScore =
  0.30 × R(GrossMargin_5Y_Median)
+ 0.25 × R(HighEndRevenueRatio)
+ 0.20 × R(RevenuePerTon)
+ 0.15 × R(BaijiuRevenueScale)
+ 0.10 × R(ASP_Trend_5Y)

GrowthQualityScore =
  0.25 × R(Revenue_CAGR_5Y)
+ 0.25 × R(DeductedNP_CAGR_5Y)
+ 0.20 × R(OCF_CAGR_5Y)
+ 0.20 × LowScore(NP_Growth_5Y_Std)
+ 0.10 × R(Revenue_NP_Match)

StabilityReturnScore =
  0.30 × LowScore(ROE_5Y_Std)
+ 0.25 × R(DividendPayout_5Y)
+ 0.20 × R(DividendStability_5Y)
+ 0.15 × R(AssetLiabilitySafety)
+ 0.10 × R(ReinvestmentDiscipline)
```

### 8. 总分

```text
BaseScore =
100 × (
  0.40 × OperatingQualityScore
+ 0.25 × BrandQualityScore
+ 0.20 × GrowthQualityScore
+ 0.15 × StabilityReturnScore
)

QualityScore =
BaseScore × RiskFactor × PurityFactor × ChannelHealthFactor
```

### 9. 最终选择

```text
BestCompany = CandidatePool 中 QualityScore 最高的公司
```

若第一名和第二名分差小于 3 分，按以下顺序打破平局：

```text
1. OperatingQualityScore 更高者胜出
2. BrandQualityScore 更高者胜出
3. ChannelHealthFactor 更高者胜出
4. ROIC_5Y_Median 更高者胜出
5. OCF_NP_5Y 更高者胜出
```

### 10. 指标计算口径

以下指标只使用公司年度报告、审计报告和交易所公告中已经披露的数据，不使用研报估算、市场传闻或主观品牌判断。

#### 10.1 HighEndRevenueRatio

```text
HighEndRevenueRatio =
高端及次高端白酒收入 / 白酒业务收入

数据来源：
仅使用年度报告中“主营业务分行业、分产品、分档次”披露的数据。

计入分子：
年报明确列示为以下名称的白酒收入：
高端酒、高档酒、中高端酒、中高档酒、次高端酒、中高价酒。

不计入分子：
普通酒、低档酒、中低档酒、其他酒、系列酒、酒类、白酒合计，以及未明确档次的品牌收入。

若公司只披露品牌、不披露档次：
不得根据品牌知名度、市场价格或个人判断划分高端/次高端，该指标记为缺失。

若公司只披露“酒类收入”但未披露白酒分档收入：
该指标记为缺失。

若公司披露口径年度之间变化：
只使用当年年报明确披露的档次口径，不手工追溯重分类。
```

#### 10.2 RevenuePerTon

```text
RevenuePerTon =
白酒业务收入 / 白酒销量

单位：
统一换算为万元/吨。

若公司披露白酒收入和白酒销量：
使用白酒口径。

若公司只披露酒类收入和酒类销量：
使用酒类收入 / 酒类销量，并标记为“酒类口径”。

若不属于“白酒收入与白酒销量”或“酒类收入与酒类销量”两种可对应组合：
该指标记为缺失。
```

#### 10.3 ASP_Trend_5Y

```text
ASP_Trend_5Y =
最近 5 年 RevenuePerTon 的年化趋势

计算方法：
对最近 5 年 RevenuePerTon 取自然对数，
用年份作为自变量做线性回归，
ASP_Trend_5Y = exp(回归斜率) - 1。

若有效年份少于 3 年：
该指标记为缺失。

若 RevenuePerTon 使用“酒类口径”：
ASP_Trend_5Y 同样标记为“酒类口径”。
```

#### 10.4 Revenue_NP_Match

```text
Revenue_NP_Match =
1 - min(abs(Revenue_CAGR_5Y - DeductedNP_CAGR_5Y) / 0.30, 1)

若 Revenue_CAGR_5Y 与 DeductedNP_CAGR_5Y 方向相反：
Revenue_NP_Match = min(Revenue_NP_Match, 0.4)

若两者均为负：
Revenue_NP_Match = min(Revenue_NP_Match, 0.2)
```

#### 10.5 AssetLiabilitySafety

```text
InterestDebtRatio =
最近一年 InterestBearingDebt / 最近一年总资产

CashDebtCoverage =
最近一年货币资金 / max(最近一年 InterestBearingDebt, 1)

ReceivableRevenueRatio =
最近一年应收票据及应收账款 / 最近一年营业收入

AssetLiabilitySafety =
0.40 × LowScore(InterestDebtRatio)
+ 0.35 × R(CashDebtCoverage)
+ 0.25 × LowScore(ReceivableRevenueRatio)
```

#### 10.6 ReinvestmentDiscipline

```text
CapexIntensity_5Y =
最近 5 年购建固定资产、无形资产和其他长期资产支付的现金合计
/ 最近 5 年营业收入合计

CIPRatio =
最近一年在建工程 / 最近一年总资产

GoodwillRatio =
最近一年商誉 / 最近一年总资产

ReinvestmentDiscipline =
0.50 × LowScore(CapexIntensity_5Y)
+ 0.25 × LowScore(CIPRatio)
+ 0.25 × LowScore(GoodwillRatio)
```

#### 10.7 品牌模块缺失处理

```text
若 BrandQualityScore 中 HighEndRevenueRatio、RevenuePerTon、ASP_Trend_5Y 三项均缺失：
BrandQualityScore 最高不得超过 ValidPool 中位数。

若 BrandQualityScore 可用指标原始权重合计低于 60%：
EligibleForBestCompany = False
```

#### 10.8 渠道健康硬触发条件

以下条件只按财务数据触发，不使用“合理解释”“季节性解释”等人工判断。

```text
t = 最近一个完整会计年度

ContractLiabilityRevenueRatio =
合同负债 / 营业收入

ReceivableRevenueRatio =
应收票据及应收账款 / 营业收入

InventoryTurnoverDays =
360 / (营业成本 / 最近两年平均存货)

RevenueYoYGrowth =
营业收入同比增速

NP_YoYGrowth =
归母净利润同比增速

OCF_YoYGrowth =
经营现金流净额同比增速
```

```text
SevereCashFlowAbnormal = True，当且仅当：
最近一年经营现金流净额 < 0，
且最近一年归母净利润 > 0，
且以下条件至少触发 2 项：

1. 最近两年经营现金流净额合计 < 0
2. 最近一年 OCF/NP < -0.20
3. OCF_NP_5Y < 0.8
4. ReceivableRevenueRatio 高于行业 75 分位
5. ContractLiabilityRevenueRatio 连续两年下降，且 RevenueYoYGrowth 连续两年下降
```

```text
SevereChannelAbnormal = True，当以下任一条件触发：

1. 渠道健康普通扣分项触发数量 >= 4

2. ContractLiabilityRevenueRatio 连续两年下降，
   且 ContractLiabilityRevenueRatio_t / ContractLiabilityRevenueRatio_t-2 - 1 <= -30%，
   且 RevenueYoYGrowth_t <= 0

3. ReceivableRevenueRatio 高于行业 90 分位，
   且 ReceivableRevenueRatio_t - ReceivableRevenueRatio_t-1 >= 5 个百分点

4. InventoryTurnoverDays 连续两年上升，
   且 InventoryTurnoverDays_t / InventoryTurnoverDays_t-2 - 1 >= 30%，
   且 RevenueYoYGrowth_t <= 0

5. 最近两年 OCF/NP 均 < 0.5，且最近两年归母净利润均 > 0

若某一条件所需数据缺失：
该条件视为未触发，不得用人工解释替代缺失数据。
```

#### 10.9 主业纯度、盈利能力与投入资本回报

```text
BaijiuRevenue =
年报分产品或分行业明确列示的白酒业务收入

若年报未列示“白酒”，但列示“酒类”，且未同时列示啤酒、葡萄酒、黄酒、保健酒、露酒或其他非白酒酒类收入：
BaijiuRevenue = 酒类收入，并标记为“酒类口径”

若年报既未列示“白酒”也未列示可对应的“酒类”收入：
BaijiuRevenue 记为缺失

BaijiuRevenueRatio =
BaijiuRevenue / 营业收入
```

```text
GrossMargin_y =
(营业收入_y - 营业成本_y) / 营业收入_y

NetMargin_y =
归母净利润_y / 营业收入_y

ROE_y =
归母净利润_y / 最近两年平均归属于母公司股东权益

GrossMargin_5Y_Median = 最近 5 年 GrossMargin_y 的中位数
NetMargin_5Y_Median = 最近 5 年 NetMargin_y 的中位数
ROE_5Y_Median = 最近 5 年 ROE_y 的中位数
ROE_5Y_Std = 最近 5 年 ROE_y 的标准差
```

```text
InterestBearingDebt_y =
短期借款_y
+ 交易性金融负债_y
+ 一年内到期的非流动负债_y
+ 长期借款_y
+ 应付债券_y
+ 租赁负债_y
+ 长期应付款中的有息融资款_y

若某项未在资产负债表或财务报表附注中单独披露：
该项按 0 处理

InvestedCapital_y =
股东权益合计_y + InterestBearingDebt_y - 货币资金_y - 交易性金融资产_y

AverageInvestedCapital_y =
(InvestedCapital_y + InvestedCapital_y-1) / 2

TaxRate_y =
min(max(所得税费用_y / 利润总额_y, 0), 0.35)

InterestExpense_y =
若年报披露利息费用，则使用利息费用；
否则使用 max(财务费用_y, 0)

EBIT_y =
利润总额_y + InterestExpense_y

NOPAT_y =
EBIT_y × (1 - TaxRate_y)

ROIC_y =
NOPAT_y / AverageInvestedCapital_y

若利润总额_y <= 0 或 AverageInvestedCapital_y <= 0：
ROIC_y 记为缺失

ROIC_5Y_Median =
最近 5 年有效 ROIC_y 的中位数

若有效 ROIC_y 少于 3 年：
ROIC_5Y_Median 记为缺失
```

#### 10.10 现金流、自由现金流与增长指标

```text
OCF_NP_5Y =
最近 5 年经营现金流净额合计 / 最近 5 年归母净利润合计

FCF_y =
经营现金流净额_y - 购建固定资产、无形资产和其他长期资产支付的现金_y

FCF_NP_5Y =
最近 5 年 FCF_y 合计 / 最近 5 年归母净利润合计

若最近 5 年归母净利润合计 <= 0：
OCF_NP_5Y 与 FCF_NP_5Y 记为缺失
```

```text
Metric_CAGR_5Y =
(Metric_t / Metric_t-4) ^ (1 / 4) - 1

适用指标：
Revenue_CAGR_5Y 使用营业收入
NP_CAGR_5Y 使用归母净利润
DeductedNP_CAGR_5Y 使用扣非归母净利润
OCF_CAGR_5Y 使用经营现金流净额

若 Metric_t-4 <= 0 或 Metric_t <= 0：
不计算 CAGR，改用最近 5 年有效同比增速的中位数

Metric_YoYGrowth_y =
Metric_y / Metric_y-1 - 1

若 Metric_y-1 <= 0：
该年度同比增速记为缺失

若有效同比增速少于 3 年：
该增长指标记为缺失

NP_Growth_5Y_Std =
最近 5 年有效 NP_YoYGrowth_y 的标准差

若有效 NP_YoYGrowth_y 少于 3 年：
NP_Growth_5Y_Std 记为缺失
```

#### 10.11 分红率与分红稳定性

```text
CashDividend_y =
年度利润分配方案中披露的现金分红金额（含税）

DividendPayout_5Y =
最近 5 年 CashDividend_y 合计 / 最近 5 年归母净利润合计

若最近 5 年归母净利润合计 <= 0：
DividendPayout_5Y 记为缺失

DividendPayoutRatio_y =
CashDividend_y / 归母净利润_y

若归母净利润_y <= 0：
DividendPayoutRatio_y 记为缺失

DividendPayoutStd_5Y =
最近 5 年有效 DividendPayoutRatio_y 的标准差

DividendStability_5Y =
1 / (1 + DividendPayoutStd_5Y)

若有效 DividendPayoutRatio_y 少于 3 年：
DividendStability_5Y 记为缺失
```

#### 10.12 监管风险硬触发条件

```text
RegulatoryMajorRisk = True，当最近 5 年上市公司主体收到以下任一官方文件：

1. 中国证监会或地方证监局出具的行政处罚决定书
2. 中国证监会出具的市场禁入决定书
3. 证券交易所出具的公开谴责或纪律处分决定
4. 财政部出具的会计信息质量检查处理决定

且官方文件事由包含以下任一关键词：

1. 虚假记载
2. 误导性陈述
3. 重大遗漏
4. 财务造假
5. 信息披露违法
6. 年报虚假
7. 资金占用
8. 违规担保

若只有立案调查公告、监管函、问询函或关注函，且尚未出现上述官方处理文件：
RegulatoryMajorRisk = False
```

#### 10.13 异常值、非经常性损益与口径变化

```text
NonRecurringRatio_y =
abs(非经常性损益_y) / max(abs(归母净利润_y), 1)

NonRecurringHigh = True，当以下任一条件触发：

1. 最近 5 年中 NonRecurringRatio_y > 30% 的年份数量 >= 3
2. 最近一年 NonRecurringRatio_y > 50%

若 NonRecurringHigh = True：
所有使用 NP_CAGR_5Y 的规则，统一改用 DeductedNP_CAGR_5Y
```

```text
Winsorize 规则：

对每一个需要横向比较的原始指标，
在 ValidPool 内计算 P5 与 P95。

若公司指标值 < P5：
用于打分的指标值 = P5

若公司指标值 > P95：
用于打分的指标值 = P95

若公司指标值位于 [P5, P95]：
用于打分的指标值 = 原始指标值
```

```text
DataBreak = True，当最近 5 年内触发以下任一条件：

1. 公司发布重大资产重组实施情况报告书
2. 公司发布重大资产购买实施情况报告书
3. 公司发布重大资产出售实施情况报告书
4. BaijiuRevenueRatio_t 与 BaijiuRevenueRatio_t-1 的差值绝对值 >= 30 个百分点
5. 营业收入_t / 营业收入_t-1 - 1 的绝对值 >= 50%，且 BaijiuRevenueRatio_t 与 BaijiuRevenueRatio_t-1 的差值绝对值 >= 15 个百分点

若 DataBreak = True：
只使用 DataBreak 发生年度及之后的数据计算 5 年类指标。

若 DataBreak 后有效年份少于 3 年：
相关 5 年类指标记为缺失。
```

## 指标说明

| 指标 | 含义 | 方向 |
|---|---|---|
| RiskFactor | 风险系数，用于剔除或惩罚财务、退市、审计、监管等重大风险 | 越高越好 |
| EligibleForBestCompany | 是否具备最终入选资格 | True 才可入选 |
| PurityFactor | 主业纯度系数，根据 BaijiuRevenueRatio 确定 | 越高越好 |
| ChannelHealthFactor | 渠道健康系数，根据合同负债、应收、存货、现金流等信号扣分 | 越高越好 |
| ROIC_5Y_Median | 最近 5 年 ROIC 中位数 | 越高越好 |
| ROE_5Y_Median | 最近 5 年 ROE 中位数 | 越高越好 |
| OCF_NP_5Y | 最近 5 年经营现金流净额合计 / 归母净利润合计 | 越高越好 |
| FCF_NP_5Y | 最近 5 年自由现金流合计 / 归母净利润合计 | 越高越好 |
| NetMargin_5Y_Median | 最近 5 年净利率中位数 | 越高越好 |
| GrossMargin_5Y_Median | 最近 5 年毛利率中位数 | 越高越好 |
| HighEndRevenueRatio | 年报明确披露的高端及次高端白酒收入 / 白酒业务收入 | 越高越好 |
| RevenuePerTon | 白酒业务收入 / 白酒销量，统一换算为万元/吨 | 越高越好 |
| BaijiuRevenueScale | 最近一年白酒业务收入规模 | 越高越好 |
| ASP_Trend_5Y | 最近 5 年 RevenuePerTon 的年化趋势 | 越高越好 |
| Revenue_CAGR_5Y | 最近 5 年营业收入复合增速 | 越高越好 |
| NP_CAGR_5Y | 最近 5 年归母净利润复合增速 | 越高越好 |
| DeductedNP_CAGR_5Y | 最近 5 年扣非归母净利润复合增速 | 越高越好 |
| OCF_CAGR_5Y | 最近 5 年经营现金流净额复合增速 | 越高越好 |
| Revenue_NP_Match | 收入增长和扣非归母净利润增长的匹配度 | 越高越好 |
| NP_Growth_5Y_Std | 最近 5 年归母净利润增速标准差 | 越低越好 |
| ROE_5Y_Std | 最近 5 年 ROE 标准差 | 越低越好 |
| DividendPayout_5Y | 最近 5 年累计现金分红 / 累计归母净利润 | 越高越好 |
| DividendStability_5Y | 最近 5 年现金分红率标准差的反向稳定性分数 | 越高越好 |
| AssetLiabilitySafety | 由 InterestBearingDebt 比率、货币资金覆盖倍数、应收收入比计算的资产负债表安全度 | 越高越好 |
| ReinvestmentDiscipline | 由资本开支强度、在建工程占比、商誉占比计算的再投资纪律 | 越高越好 |
